# World Mosaic – International Cultural Festival

**Tagline:** One World. Many Cultures. One Celebration.  
**Theme:** A Journey Around the World  

**Proposed dates:** 23–24 January 2027 · 10:00 AM – 9:00 PM  
**Venue:** Yashobhoomi (India International Convention and Expo Centre), Dwarka, New Delhi  

This is a student project digital prototype for BBA – EventTech & Quality Management.

## Website pages

- Home
- About the Festival
- Country Pavilions (13 proposed countries)
- Programme (full two-day run sheet)
- Registration (RSVP form with categories, visit date, accessibility, consent)
- Ticket confirmation + QR code (demo)
- Contact, Privacy, Terms
- Admin dashboard shell

## Features demonstrated

- Mobile-friendly public website
- Working registration form → unique ticket ID + QR code
- Guest categories (General, Student, VIP, Performer, Exhibitor)
- Visit date selection (Day 1 / Day 2 / Both)
- Check-in ready ticket page
- No cron jobs or scheduled background tasks

## How to deploy (student-friendly)

1. Upload this project to a GitHub repository (web upload is fine).
2. Import the repository into [Vercel](https://vercel.com).
3. Deploy. No terminal required.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Project note

Dates, venue, attendance, budget, countries and operational arrangements are planning assumptions until confirmed. This prototype is for academic demonstration of the visitor journey, registration, QR pass and digital check-in concepts required by the course handbook.
